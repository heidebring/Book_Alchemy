# Book Alchemy Project

This project lets you manage authors and books which are stored in the file library.sqlite.

## Installation

To install this project, simply clone the repository and install the dependencies in requirements.txt using `pip`

## Usage

To use this project, run the following command - `python app.py`. This will start the flask application and you can manage your books. Adding add_author to the url will allow you to add an author. Adding add_book to the url will allow you to add a book.
